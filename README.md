# Laboratorio 11 — Introducción a la visualización de datos

Taller práctico sobre detección de valores atípicos y creación de gráficos básicos, usando Excel y Python.

## Contenido

- `Bike_Sales_Outlier_Lab.xlsx` — dataset de ventas de bicicletas, con la tabla dinámica, el ordenamiento y las fórmulas (GRANDE/PEQUEÑO) usadas para encontrar el valor atípico.
- `Lab11_Visualizacion_de_Datos.ipynb` — notebook de Google Colab con el mismo análisis hecho en Python (pandas + matplotlib + seaborn), más los gráficos del segundo ejercicio de práctica.

## Ejercicio 1 — Valores atípicos en ventas de bicicletas

Se identificó que el **19 de diciembre de 2021** tuvo una cantidad de ventas (43 unidades) muy por encima del resto de los días, causada principalmente por el pedido **000261765**. Se muestra cómo detectarlo con tabla dinámica, ordenamiento, gráfico de dispersión y las funciones GRANDE/PEQUEÑO, y qué hacer con él (eliminarlo o normalizarlo).

## Ejercicio 2 — Gráficos de escenarios reales

Cuatro visualizaciones adicionales: calificaciones por asignatura, tiempos de carga de sitios web, horas de estudio vs. rendimiento, y distribución de salarios por departamento.

## Cómo correrlo

Abre el notebook en [Google Colab](https://colab.research.google.com/) y ejecuta las celdas en orden. El Excel se carga directamente desde este repositorio (raw), no hace falta subirlo manualmente.
